# 📝 To-Do List App

This is a simple and user-friendly To-Do List web application created using HTML, CSS, and JavaScript. It allows users to manage their daily tasks easily by adding, editing, and deleting tasks.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 💾 Save tasks using browser localStorage
- 🔄 Tasks remain available after refreshing the page
- 📱 Clean and easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## 📌 How It Works

Users can enter a task and add it to the list. Tasks can be edited or deleted whenever required. The application uses localStorage to save the tasks in the browser, so the tasks are not lost when the page is refreshed.

## 🎯 Purpose

The purpose of this project is to practice HTML, CSS, and JavaScript and to understand how JavaScript can be used to create an interactive web application and store data using localStorage.
